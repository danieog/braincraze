# BrainCraze Source Export

This folder contains selected account, onboarding, verification, membership, and localization implementation files from the original project. Repository-relative paths are preserved.

Included:
- Next.js pages and API routes for account access, verification, onboarding, billing, and administration.
- Shared UI components and server-side modules used by those features.
- Database SQL, operational scripts, and implementation documentation.

Excluded:
- Dependency manifests and lockfiles.
- Tests and browser-test configuration.
- Environment files and generated or installed files.

This is source code for adapting into an existing application, not a standalone project scaffold.
